# GGN Morandi Themes

Four Morandi palettes for GazelleGames (GGn), all keeping the original Blue Night layout and components. Pick one and paste its URL into GGn **External CSS** settings, save, then hard-refresh. No userscript or extra dependency is required.

## Morandi Dark Green (dark)

A muted, deep-green dark theme with subdued green-grey surfaces, warm readable text, and restrained accents.

```text
https://acesaint.github.io/ggn-morandi-1/ggn-morandi-dark-green.css
```

## Morandi Warm Paper (light)

A light warm-paper theme: limestone-white surfaces, sage controls, and a restrained terracotta accent.

```text
https://acesaint.github.io/ggn-morandi-1/ggn-morandi-warm-paper.css
```

## Morandi Warm Sand (light)

A light warm-sand theme built around the natural paper tone `#F5F2EB`: sandstone layering, warm-ink text, and a quiet clay accent. Pairs with Night Sand below.

```text
https://acesaint.github.io/ggn-morandi-1/ggn-morandi-warm-sand.css
```

## Morandi Night Sand (dark)

The dark companion to Warm Sand: warm charcoal-brown surfaces, parchment text, low-saturation clay accents, and sage-grey controls — the sand paper theme at night.

```text
https://acesaint.github.io/ggn-morandi-1/ggn-morandi-night-sand.css
```

jsDelivr alternatives (any theme):

```text
https://cdn.jsdelivr.net/gh/acesaint/ggn-morandi-1@main/ggn-morandi-dark-green.css
https://cdn.jsdelivr.net/gh/acesaint/ggn-morandi-1@main/ggn-morandi-warm-paper.css
https://cdn.jsdelivr.net/gh/acesaint/ggn-morandi-1@main/ggn-morandi-warm-sand.css
https://cdn.jsdelivr.net/gh/acesaint/ggn-morandi-1@main/ggn-morandi-night-sand.css
```

To switch themes, replace the URL in **External CSS** and hard-refresh.

## 中文说明

本仓库提供四套 GGn 莫兰迪主题，均保留 Blue Night 原有布局与组件，任选其一填入 GGn 的 **External CSS** 设置并保存，硬刷新即可：

- **深绿色**（深色）：低饱和绿灰表面、暖调文字；填入上方 Morandi Dark Green 地址。
- **暖纸浅色**（浅色）：石灰白纸面、灰鼠尾草控件、克制的陶土强调色；填入上方 Morandi Warm Paper 地址。
- **暖沙米色**（浅色）：自然纸感沙米底色 `#F5F2EB`、沙岩层次、暖墨文字与陶土强调；填入上方 Morandi Warm Sand 地址。
- **夜沙炭褐**（深色）：暖沙的入夜配套版——炭褐表面、羊皮纸文字、低饱和陶土强调与灰鼠尾草控件；填入上方 Morandi Night Sand 地址。

四套主题互切只需更换 External CSS 地址后硬刷新；样式表均无需额外脚本或依赖。项目文档（令牌规范、执行计划、验收报告与可复现校验脚本）见仓库根目录相应 Markdown 与 Python 文件（sand 主题见 `SAND_THEME_TOKENS.md` 与 `SAND_THEME_ACCEPTANCE_REPORT.md`）。
