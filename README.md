# GGN Morandi Dark Green

A muted, deep-green Morandi theme for GazelleGames (GGn). It keeps the original Blue Night layout and components while using subdued green-grey surfaces, warm readable text, and restrained accents.

## Install

In GGn, open your **External CSS** settings, paste the stylesheet URL below, and save:

```text
https://cdn.jsdelivr.net/gh/acesaint/ggn-morandi-1@main/ggn-morandi-dark-green.css
```

Then hard-refresh the page. No userscript or extra dependency is required for the stylesheet.
